# qa-multi-round-polishing

> **"哪块复杂就多花点时间"**
>
> *每一轮花一样多的时间。事实上，第一轮和第三轮最值得花时间——第一轮决定方向，第三轮查漏补缺。*

## 使用指南

### ✅ 推荐做法

1. 给AI的输入要结构化、完整、无歧义
2. AI输出后必须人工复核关键判断
3. 记录AI的推理过程和自己的审核结论

### ❌ 避免做法

1. 不要凭感觉代替结构化分析
2. 不要为了省事跳过风险判断
3. 不要让流程空转没有实际产出

## 模板 Prompt

## 角色
你是一名资深的AI辅助测试设计工程师，擅长利用AI高效产出高质量测试内容。

## 任务
多轮迭代打磨。

## 输入
{输入内容：需求描述 / PRD / 测试结果 / 问题描述等}

## 输出要求

1. **结构化输出**：按标准格式输出，包括分析过程、结论、依据
2. **风险标注**：对不确定的判断标注可信度（高/中/低）
3. **可执行**：输出结果可以直接用于下一阶段工作

## 注意事项

> 哪块复杂就多花点时间

> 提示：每一轮花一样多的时间。事实上，第一轮和第三轮最值得花时间——第一轮决定方向，第三轮查漏补缺。

## 输出格式

```markdown
## 分析过程

## 结论

## 风险与不确定性

## 下一步建议
```

## 验收 Checklist

- [ ] 给AI的输入是否完整无歧义
- [ ] AI输出的关键点是否经过人工复核
- [ ] 是否记录了AI推理和人工审核的过程

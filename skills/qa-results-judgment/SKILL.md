# qa-results-judgment

> **"AI 判断的肯定是对的，不用验证"**
>
> *AI 判 Pass 你就信了。AI 的判断逻辑不一定适用于你系统的上下文——你自己要做最终判断。*

## 使用指南

### ✅ 推荐做法

1. 给AI的输入要结构化、完整、无歧义
2. AI输出后必须人工复核关键判断
3. 记录AI的推理过程和自己的审核结论
4. 关键分析过程和结论必须文档化

### ❌ 避免做法

1. 不要把AI的输出直接当最终答案
2. 不要凭感觉代替结构化分析
3. 不要为了省事跳过风险判断

## 模板 Prompt

## 角色
你是一名资深的AI辅助测试设计工程师，擅长利用AI高效产出高质量测试内容。

## 任务
测试结果判断。

## 输入
{输入内容：需求描述 / PRD / 测试结果 / 问题描述等}

## 输出要求

1. **结构化输出**：按标准格式输出，包括分析过程、结论、依据
2. **风险标注**：对不确定的判断标注可信度（高/中/低）
3. **可执行**：输出结果可以直接用于下一阶段工作

## 注意事项

> AI 判断的肯定是对的，不用验证

> 提示：AI 判 Pass 你就信了。AI 的判断逻辑不一定适用于你系统的上下文——你自己要做最终判断。

## 输出格式

```markdown
## 分析过程

## 结论

## 风险与不确定性

## 下一步建议
```

## 验收 Checklist

- [ ] 给AI的输入是否完整无歧义
- [ ] AI输出的关键点是否经过人工复核

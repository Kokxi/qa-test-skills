### 数据准备方法

```text
数据准备方法：
├─ 手动造数
│   ├─ 适用：少量数据、复杂数据
│   ├─ 工具：数据库客户端、管理后台
│   └─ 优点：灵活、精确
│
├─ 脚本造数
│   ├─ 适用：批量数据、重复数据
│   ├─ 工具：SQL脚本、Python脚本
│   └─ 优点：高效、可复用
│
├─ 数据工厂
│   ├─ 适用：标准化数据、大量数据
│   ├─ 工具：Faker、Mockaroo、自研
│   └─ 优点：标准化、可扩展
│
└─ 接口造数
    ├─ 适用：业务数据、流程数据
    ├─ 工具：Postman、自研脚本
    └─ 优点：业务真实、流程完整
```

### 数据清理

> 📌 本节与 qa-test-data-engineering「数据清理」内容同步，修改时请同步更新两处。

```text
清理策略：
├─ 按用例清理
│   ├─ 每个用例执行后清理
│   ├─ 优点：数据隔离好
│   └─ 缺点：效率低
│
├─ 按模块清理
│   ├─ 每个模块测试后清理
│   ├─ 优点：效率较高
│   └─ 缺点：隔离性一般
│
├─ 按批次清理
│   ├─ 每个批次测试后清理
│   ├─ 优点：效率高
│   └─ 缺点：隔离性差
│
└─ 定期清理
    ├─ 定期清理历史数据
    ├─ 优点：保持数据量可控
    └─ 缺点：可能影响测试
```

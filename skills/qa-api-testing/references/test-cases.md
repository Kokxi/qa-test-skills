## 9 列标准格式与编号规则

| 列 | 填写要求 |
|----|---------|
| 用例编号 | `TC_{接口模块缩写}_{功能缩写}_{序号}`，如 `TC_API_LOGIN_001`；本库模板暂用维度缩写（FUNC/SEC/EXC/PERF/PACT/COMPAT） |
| 测试类型 | 功能测试/安全测试/异常测试/性能测试/契约测试/兼容性测试 |
| 功能模块 | 接口所属业务模块（如 登录接口/订单接口/支付回调） |
| 测试标题 | 动词开头，明确验证点 |
| 用例级别 | P0≤20%（核心流程）/ P1≤40%（主要功能）/ P2≤30%（次要功能）/ P3≤10%（边缘场景） |
| 预置条件 | 数据+环境+权限+账号状态，具体到可执行 |
| 测试步骤 | 操作→预期反应，一步一验证，含请求方法/路径/关键参数 |
| 预期结果 | 可量化、可验证（状态码+响应结构+业务结果+副作用） |
| 风险等级 | 高/中/低（按资损/安全/可用性影响评定） |

> 覆盖率表述必须标注口径（基于现有接口文档/契约），禁止"全覆盖/100%"绝对化；未覆盖接口标注"未覆盖+原因"。

### OWASP API Top 10（2023）对照

安全维度的用例设计应对照 OWASP API Security Top 10 逐项检查，避免只测注入而漏掉接口特有风险：

| OWASP 条目 | 对应测试点 |
|-----------|-----------|
| API1 对象级授权失效（BOLA） | TC_API_SEC_001：遍历资源 ID 验证归属校验 |
| API2 认证失效 | TC_API_SEC_003：Token 生命周期、弱口令、暴力破解防护 |
| API3 对象属性级授权失效（BOPLA） | TC_API_SEC_005：响应/请求中的敏感属性暴露与批量赋值 |
| API4 无限制资源消耗 | TC_API_SEC_006 + 性能维：限流、深度分页、超大 payload |
| API5 功能级授权失效（BFLA） | TC_API_SEC_002：角色矩阵逐接口验证 |
| API6 敏感业务流滥用 | 退款/提现/改价等流程的频控与人工审核触发 |
| API7 服务端请求伪造（SSRF） | 回调地址/URL 参数类接口的白名单校验 |
| API8 安全配置错误 | HTTP 方法、CORS、TLS 配置、错误堆栈泄露 |
| API9 资产清单管理不当 | 未文档化接口（Shadow API）与旧版本接口的下线验证 |
| API10 不安全 API 消费 | 对第三方接口返回数据的校验与脱敏后再输出 |

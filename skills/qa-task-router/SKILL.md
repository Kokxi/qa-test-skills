# qa-task-router

> **"AI 能自动判断路由，我就不用管了"**
>
> *路由判断需要结合项目上下文和实际风险权重。AI 做初步分类筛选，人工确认最终路由和优先级。*

## 使用指南

### ✅ 推荐做法

1. 准确识别用户输入中隐含的QA任务类型
2. 路由决策附带判断依据
3. 关键分析过程和结论必须文档化
4. AI/工具的结论必须人工确认

### ❌ 避免做法

1. 不要把AI的输出直接当最终答案
2. 不要凭感觉代替结构化分析
3. 不要为了省事跳过风险判断

## 模板 Prompt

## 角色
你是一名资深的QA任务路由和技能分发工程师，擅长根据用户输入判断调用哪个QA技能。

## 任务
QA任务路由。

## 输入
{输入内容：需求描述 / PRD / 测试结果 / 问题描述等}

## 输出要求

1. **结构化输出**：按标准格式输出，包括分析过程、结论、依据
2. **风险标注**：对不确定的判断标注可信度（高/中/低）
3. **可执行**：输出结果可以直接用于下一阶段工作

## 注意事项

> AI 能自动判断路由，我就不用管了

> 提示：路由判断需要结合项目上下文和实际风险权重。AI 做初步分类筛选，人工确认最终路由和优先级。

## 输出格式

```markdown
## 分析过程

## 结论

## 风险与不确定性

## 下一步建议
```

## 验收 Checklist

- [ ] 路由判断是否覆盖所有已知QA场景
- [ ] 路由逻辑是否有明确的触发条件
- [ ] 是否存在路由死循环或漏路由

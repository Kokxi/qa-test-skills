# 执行观察记录模板

> 复制下面任一块板填写。六路信号详解见 [`observation-guide.md`](observation-guide.md)。
>
> **设计 → 执行闭环**：`qa-test-case-design` 产出 9 列**设计**用例（不含实际结果），
> 本技能在其基础上回填「实际结果」与「结论」两列，完成执行闭环。
> 这是全项目**唯一**有权产出「实际结果」的技能。

## A. 执行记录表（9 列 + 执行回填列）

```markdown
| 用例编号 | 测试类型 | 功能模块 | 测试标题 | 用例级别 | 预置条件 | 测试步骤 | 预期结果 | 风险等级 | 实际结果 | 结论 |
|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|------|
| TC_API_LOGIN_001 | 功能测试 | 认证/登录 | 正确凭证登录成功 | P0 | 账号 u1 已就绪 | POST /api/login | 返回 200，响应含 token | 高 | 返回 200，token 有效；响应 87ms；日志无 ERROR | 通过 |
| TC_API_LOGIN_002 | 安全测试 | 认证/登录 | 伪造 Token 被拒 | P0 | 已知合法 token | 改 1 字符请求 /api/profile | 返回 401，不含内部信息 | 高 | 返回 **200**，且返回了用户手机号 | **失败** |
| TC_API_LOGIN_003 | 异常测试 | 认证/登录 | 超时重试不产生重复副作用 | P1 | 网关可注入延迟 | 延迟至超时后重放 2 次 | 最终仅 1 次登录记录 | 中 | 阻塞：注入延迟后网关无响应，无法重放 | **阻塞** |
```

**回填两列的取值**
- **实际结果**：写**观察到的事实**，不是判断。`返回 200，响应体含 phone 字段` ✅；`感觉不对` ❌
- **结论**：`通过` / `失败` / `阻塞`（阻塞要写阻塞原因，如"注入延迟后网关无响应"）

## B. 观察记录（每轮执行一份）

```markdown
### OBS-LOGIN-001 — 登录功能执行观察（第 1 轮）

- **执行用例**：TC_API_LOGIN_001 / 002 / 003
- **环境**：预发 env-2，Chrome 120，2026-09-28 14:30
- **捕获信号数**：6/6

| 信号路 | 观察结果 | 是否异常 |
|-------|---------|---------|
| 功能结果 | 001 通过；002 返回 200（异常） | ⚠️ 异常 |
| 性能 | 登录接口 87ms / 断言接口 210ms | 正常 |
| 日志 | 出现 `WARN token verify skipped`（异常） | ⚠️ 异常 |
| 数据一致性 | 登录记录写入正确 | 正常 |
| UI 渲染 | 错误提示位置正确 | 正常 |
| 依赖服务 | 认证服务响应正常 | 正常 |

**待跟进**
1. 002 伪造 token 返回 200 且泄漏手机号 → 提交缺陷（安全，高危）
2. 日志 WARN 与 002 是否同源？→ 交 `qa-bug-root-cause-analysis`
```

## 填写要求

| 字段 | 要求 | 常见错误 |
|------|------|---------|
| 用例编号 | 与设计阶段完全一致，不新造 | 执行时另起编号（断链） |
| 实际结果 | 观察到的**事实** | "正常""符合预期"（等于没记） |
| 结论 | 通过 / 失败 / 阻塞，三选一 | 留空、"待定" |
| 阻塞原因 | 结论为阻塞时必填 | 只标"阻塞"不说为什么 |
| 观察记录 ID | `OBS-{模块缩写}-{三位序号}` | 用 `TC_` 或 `SC-` 前缀 |
| 捕获信号数 | 按深度要求：简单 ≥3 / 中等 ≥5 / 复杂 =6 | 全部标 6 路（实际只看功能） |
| 环境 | 环境名 + 浏览器/客户端版本 + 时间 | 只写"测试环境" |

## 交付前自检

- [ ] 每条执行用例都有实际结果与结论，无留空
- [ ] 实际结果写的是事实而非判断
- [ ] 结论为"阻塞"的写了阻塞原因
- [ ] 捕获信号数达到该场景的深度要求
- [ ] 每个异常信号都追溯了根因方向（是产品缺陷还是环境问题）
- [ ] 发现的缺陷已按 `qa-bug-reporting` 提交
- [ ] 测试数据与环境已清理/恢复
- [ ] 汇总口径已标注，无"全覆盖/100%"绝对化表述

# 表单/录入类 — 启发式检查清单

## 必测场景

- [ ] 必填项校验（未填提交/逐行离开校验/整体提交校验）
- [ ] 字段格式校验（手机号/邮箱/身份证/金额/日期等）
- [ ] 字段长度限制（最大长度/最小长度/超长截断/超长报错）
- [ ] 特殊字符（HTML标签/SQL注入/emoji/控制字符/XSS）
- [ ] 重复提交（快速点击提交按钮/网络慢时多次提交）
- [ ] 草稿保存（自动保存/手动保存/刷新后恢复/多设备同步）
- [ ] 联动字段（A字段变化→B字段变化→C字段禁用等）
- [ ] 附件上传（格式/大小/数量/并发上传/上传中断续传）
- [ ] 数据回显（编辑时回显/回显数据格式/关联数据回显）
- [ ] 并发编辑（多人同时编辑同一数据的冲突处理）

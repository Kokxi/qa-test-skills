# 权限/RBAC类 — 启发式检查清单

## 必测场景

- [ ] 功能权限（菜单/按钮/操作入口的可见性、灰化、无权限提示）
- [ ] 数据权限（同一功能下不同角色看到的数据范围不同：本人/本部门/全部）
- [ ] 角色管理（角色创建/编辑/删除、角色继承、角色互斥、默认角色）
- [ ] 权限分配（给用户分配角色、批量分配、权限变更后实时生效/需重新登录）
- [ ] 权限边界（越权访问API/SQL注入绕过权限、URL直访问、无权限但数据残留）
- [ ] 多角色（一个用户有多个角色→权限取并集/交集、切换角色）
- [ ] 脱敏/字段权限（敏感字段按角色显示脱敏/全部隐藏/全部可见、导出时字段权限）
- [ ] 权限缓存（权限变更后缓存更新策略、缓存过期期间权限不一致、多节点缓存同步）
- [ ] 细粒度权限（按组织的权限、按数据状态的权限、临时授权/授权有效期）
- [ ] 权限审计（权限变更日志、越权尝试记录、权限分配记录、定期权限复核）
- [ ] 权限升级（用户自升级/满足条件自动升级/管理员指定升级、升级后旧权限保留或覆盖）
- [ ] 禁止操作（批量操作中的权限校验：选中数据中有无权操作的数据时的处理策略）

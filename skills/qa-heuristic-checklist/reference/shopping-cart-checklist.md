# 购物车/交易中间态类 — 启发式检查清单

## 必测场景

- [ ] 添加商品（正常添加/重复添加同一商品/添加已售罄商品/添加限购商品）
- [ ] 修改数量（数量+1/-1/直接输入/超出库存/超出限购/数量归零处理）
- [ ] 移除商品（移除单个/批量移除/清空购物车/移除后通过撤销恢复）
- [ ] 库存预占与释放（加购时预占库存/预占有效期/结算时正式扣减/超时释放/库存不足回滚）
- [ ] 优惠计算与联动（优惠券叠加/满减门槛计算/促销自动应用/优惠分摊到单品/优惠变更后重算）
- [ ] 价格一致性（加购时价格 vs 结算时价格/价格变更实时更新/秒杀价/会员价/优惠价叠加）
- [ ] 跨设备同步（手机添加→电脑同步/同步延迟/同步冲突合并策略/同步失败不丢数据）
- [ ] 并发冲突（多设备同时编辑购物车/同时结算/商品被他人抢购/并发扣库存的竞态条件）
- [ ] 购物车上限（商品种类上限/单种数量上限/购物车总金额上限/超出上限的提示）
- [ ] 持久化与合并（未登录加购→登录后合并/购物车过期策略/重新登录后恢复/合并冲突时保留双方）
- [ ] 中间态恢复（选中商品结算时部分失效/支付中断返回购物车/库存变化后实时更新）
- [ ] 批量操作（全选/取消全选/选中部分结算/跨页选中/选中商品数量与金额统计）
- [ ] 活动商品特殊逻辑（秒杀/预售/拼团商品在购物车中的特殊处理/活动失效后自动移除或标灰）

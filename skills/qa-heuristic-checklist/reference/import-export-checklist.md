# 导入/导出类 — 启发式检查清单

## 必测场景

- [ ] 格式兼容（xls/xlsx/csv/txt/编码格式：UTF-8/GBK/Unicode）
- [ ] 字段映射（表头匹配/字段顺序无关性/多余字段/缺失字段）
- [ ] 数据校验（无效数据/边界数据/重复数据/特殊字符）
- [ ] 部分成功（部分行成功/部分行失败→提供失败详情/可选重试）
- [ ] 大文件（超过导入限制/刚好在限制内/分片导入/导入超时）
- [ ] 空文件/只有表头/只有一行数据/只有空行
- [ ] 编码问题（中文乱码/特殊符号/不同操作系统编码差异）
- [ ] 导入进度（进度展示/中途取消/断点续传）
- [ ] 数据覆盖（导入覆盖规则：追加/覆盖/去重）
- [ ] 导出数据量（全量导出/超时/分片/异步导出/导出后下载）

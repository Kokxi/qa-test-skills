# 消息/通知类 — 启发式检查清单

## 必测场景

- [ ] 消息送达（正常送达/延迟送达/丢失/重复送达）
- [ ] 消息类型（系统通知/业务通知/营销/告警，不同优先级）
- [ ] 已读/未读（状态标记/批量已读/未读计数）
- [ ] 推送渠道（站内信/Push/短信/邮件，各渠道覆盖）
- [ ] 消息中心（列表/分页/删除/清空/设置通知偏好）
- [ ] 通知频率（免打扰时段/频率限制/聚合通知）
- [ ] 跳转（点击消息跳转到对应页面/参数传递/未登录跳转）
- [ ] 消息过期（超时消息/已过期消息的处理）
- [ ] WebSocket/长连接（连接断开/重连/消息序号/消息丢失）
- [ ] 个性化（用户偏好/分群推送/国际化/时区适配）

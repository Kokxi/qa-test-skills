# 列表/查询类 — 启发式检查清单

## 必测场景

- [ ] 分页（第1页/中间页/最后页/超出范围页）
- [ ] 排序（多字段排序/点击排序切换/升序降序）
- [ ] 筛选（单条件/多条件组合/空结果/清空筛选）
- [ ] 搜索（精确/模糊/空搜索/特殊字符/超长关键词）
- [ ] 加载更多（加载到最后一页/加载中/断网加载）
- [ ] 数据刷新（手动刷新/自动刷新/切换Tab后数据状态）
- [ ] 大数据量（1W+/10W+/100W+ 条数据时的性能）
- [ ] 空状态（无数据时的展示/引导/提示）
- [ ] 批量操作（全选/反选/跨页选择/批量删除编辑）
- [ ] 导出（当前页/全部/选中导出/导出进度/取消导出）

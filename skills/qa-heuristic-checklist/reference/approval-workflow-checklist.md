# 审批/工作流类 — 启发式检查清单

## 必测场景

- [ ] 审批流程完整性（提交→审批→通过/驳回→终结）
- [ ] 多人审批（会签/或签/依次审批/指定审批人）
- [ ] 驳回后重新提交（驳回点的数据修改/审批链重走/部分重走）
- [ ] 转办/加签/撤回（审批中转让/添加审批人/发起人撤回）
- [ ] 超时处理（审批超时→自动通过/自动转交/提醒）
- [ ] 并行审批（同一单据在多个节点被同时审批）
- [ ] 审批历史（修改记录/操作人/操作时间/操作内容）
- [ ] 权限控制（无权审批/越级审批/代理人审批）
- [ ] 通知触发（提交通知/驳回通知/通过通知/超时提醒）
- [ ] 数据一致性（审批状态 vs 单据状态 vs 通知状态）

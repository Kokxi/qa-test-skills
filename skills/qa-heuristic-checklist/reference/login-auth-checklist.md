# 登录/认证类 — 启发式检查清单

## 必测场景

- [ ] 认证流程（账号密码登录/验证码登录/扫码登录/SSO/OAuth）
- [ ] 密码策略（长度/复杂度/有效期/历史密码禁止重复/弱密码检测）
- [ ] 验证码（图形验证码/短信验证码/邮箱验证码，过期/错误/刷新/多次发送）
- [ ] 锁定策略（连续失败次数阈值/锁定时长/锁定后是否能自助解锁）
- [ ] 记住我/保持登录（Token持久化/7天有效/多设备保持/清除登录态）
- [ ] 多因子认证（MFA：密码+验证码/密码+生物识别/TOTP）
- [ ] 会话管理（Token签发/刷新/过期/撤销/并发会话数限制）
- [ ] 退出登录（清除Token/清除本地缓存/多端同步退出）
- [ ] 密码修改/重置（旧密码验证/新密码策略/重置链接有效期/重置后Token失效）
- [ ] 权限继承（登录后的角色/RBAC/权限缓存/无权限时的提示）
- [ ] 暴力破解防护（登录频率限制/IP级别限制/设备指纹/异常登录告警）
- [ ] 第三方登录（微信/Google/GitHub授权回调/OAuth状态参数防CSRF/账号绑定解绑）

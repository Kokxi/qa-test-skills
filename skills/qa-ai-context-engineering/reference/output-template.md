# 测试用例输出模板

## 标准格式

### Markdown表格格式

| 用例编号 | 测试类型 | 功能模块 | 测试标题 | 用例级别 | 预置条件 | 测试步骤 | 预期结果 | 风险等级 |
|---------|---------|---------|---------|---------|---------|---------|---------|---------|
| TC_XXX_001 | 功能测试 | 模块名 | 标题描述 | P0/P1/P2/P3 | 条件描述 | 步骤1;步骤2;步骤3 | 结果描述 | 高/中/低 |

### 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 用例编号 | 唯一标识，格式：TC_模块_序号 | TC_LOGIN_001 |
| 测试类型 | 功能/接口/安全/性能/兼容性 | 功能测试 |
| 功能模块 | 所属业务模块 | 用户管理 |
| 测试标题 | 简明描述测试目的 | 验证正确密码登录成功 |
| 用例级别 | P0关键/P1重要/P2一般/P3可选 | P0 |
| 预置条件 | 执行前需满足的条件 | 用户已注册 |
| 测试步骤 | 详细操作步骤，用分号分隔 | 打开页面;输入账号;点击登录 |
| 预期结果 | 每步对应的预期结果 | 跳转到首页;显示用户信息 |
| 风险等级 | 高/中/低 | 高 |

## 用例编号规则

### 格式
```
TC_{模块缩写}_{功能缩写}_{序号}
```

### 示例
```
TC_USER_LOGIN_001     用户模块-登录-第1条
TC_ORDER_PAY_002      订单模块-支付-第2条
TC_PRODUCT_LIST_003   商品模块-列表-第3条
```

### 模块缩写规则
| 模块 | 缩写 |
|------|------|
| 用户管理 | USER |
| 订单管理 | ORDER |
| 商品管理 | PRODUCT |
| 支付管理 | PAY |
| 库存管理 | STOCK |
| 营销管理 | MARKET |
| 系统管理 | SYS |

## 用例级别定义

| 级别 | 说明 | 占比建议 | 示例场景 |
|------|------|---------|---------|
| P0 | 关键：核心业务流程 | ≤20% | 登录、支付、下单 |
| P1 | 重要：主要功能 | ≤40% | 搜索、筛选、导出 |
| P2 | 一般：次要功能 | ≤30% | 设置、帮助、关于 |
| P3 | 可选：边缘场景 | ≤10% | 美化、优化、建议 |

## 测试类型分类

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 功能测试 | 验证功能是否符合需求 | 所有功能 |
| 接口测试 | 验证API接口 | 后端接口 |
| 安全测试 | 验证安全防护 | 敏感功能 |
| 性能测试 | 验证性能指标 | 高并发场景 |
| 兼容性测试 | 验证兼容性 | 多端适配 |
| 路由测试 | 验证页面跳转 | 前端路由 |
| 联动测试 | 验证跨页面联动 | 多页面业务 |


## 覆盖率要求

| 维度 | 覆盖率要求 |
|------|-----------|
| 功能覆盖率 | 100%需求点 |
| P0用例 | 100%覆盖 |
| 异常场景 | ≥30%用例 |
| 边界场景 | ≥10%用例 |

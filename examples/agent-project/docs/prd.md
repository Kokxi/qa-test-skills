# AI 客服 Agent 需求文档

## 项目概述
本项目是一个基于大语言模型的 AI 客服 Agent，为用户提供订单查询、退货申请、商品咨询等自助服务，需要人工无法覆盖的时段提供 7×24 小时服务。

## Agent 基本行为规范

### 1.1 角色边界
- Agent 身份：电商平台 AI 客服助手
- 允许行为：查询订单、查询物流、发起退货申请、商品咨询、常见问题解答
- 禁止行为：修改订单金额、直接退款、删除订单、访问其他用户数据
- 角色保持：任何时候不得声称自己是人类客服或泄露系统 Prompt

### 1.2 对话能力
- 支持多轮对话，保持上下文记忆（最近 10 轮）
- 理解意图：退货、退款、查询、投诉、咨询等意图识别
- 未知问题处理：承认"不知道"并引导人工客服，不得编造

### 1.3 工具调用
- 可用工具：
  - `query_order(order_id)`：查询订单状态
  - `query_logistics(order_id)`：查询物流信息
  - `apply_refund(order_id)`：发起退货申请（需用户确认）
  - `search_product(keyword)`：商品搜索
- 工具调用约束：
  - 调用前必须确认用户意图（高影响操作需二次确认）
  - 不得在用户未授权时调用 `apply_refund`
  - 工具参数必须从对话中正确提取

## 安全要求

### 2.1 Prompt 注入防护
- 拒绝执行用户指令中与 Agent 系统指令冲突的内容
- 拒绝泄露系统 Prompt、内部指令、工具定义
- 识别并拒绝间接注入（通过网页/文档内容携带的恶意指令）

### 2.2 数据隔离
- 只能访问当前用户的订单数据
- 不得透露其他用户的信息（订单号、金额、地址、联系方式）
- 敏感信息脱敏：手机号中间4位掩码、地址隐藏详细门牌号

### 2.3 操作权限
- 退款/退货等高影响操作需用户明确授权 + 人工审核（HITL）
- 单次会话最多发起 3 次退款申请（防滥用）
- 速率限制：同一用户每分钟最多 20 次请求

## 非功能要求

### 3.1 幻觉控制
- 订单信息必须来自工具查询结果，不得编造
- 商品信息回答需引用商品库数据
- 不确定时必须声明"不确定"，不得猜测

### 3.2 可靠性
- 上游工具超时（>5秒）时优雅降级：提示"系统繁忙"并重试
- 模型不可用时回退到固定话术 + 转人工
- 会话稳定性：连续运行 24 小时不崩溃

### 3.3 性能
- 首响应时间 < 2 秒
- 工具调用成功率 > 99%
- 支持 100 并发用户

## 验收标准

1. 9 类意图识别准确率 ≥ 95%
2. Prompt 注入攻击拦截率 100%（测试集）
3. 幻觉率 < 5%（事实性抽查）
4. 所有工具调用可审计（日志记录参数和结果）
5. 未授权的高影响操作 100% 被拦截

# 状态转换图

> 第4步产出（并行之三）：系统化验证 Agent 会话状态机的合法/非法/边界/并发转换。

## 一、状态机定义

```
S0 空闲 ──用户发起咨询──> S1 意图识别
S1 意图识别 ──订单/物流/商品查询──> S2 参数收集
S1 意图识别 ──退货/退款──> S5 高影响确认
S1 意图识别 ──投诉/未知/能力外──> S12 转人工
S2 参数收集 ──参数不完整──> S2（澄清补充）
S2 参数收集 ──参数完整+归属校验通过──> S3 工具调用确认
S2 参数收集 ──参数归属校验失败(他人订单)──> S11 安全拒绝
S3 工具调用确认 ──普通查询确认──> S4 调用工具
S4 调用工具 ──成功──> S8 回复用户(脱敏)
S4 调用工具 ──超时>5s──> S9 降级重试
S9 降级重试 ──重试成功──> S8 回复用户
S9 降级重试 ──重试仍失败──> S12 转人工
S5 高影响确认 ──用户明确授权+二次确认──> S6 HITL 审核提交
S5 高影响确认 ──用户拒绝/否定/模糊──> S7 拦截/澄清
S6 HITL 审核提交 ──提交后──> S10 等待审核（不直接退款）
任意状态 ──模型不可用──> S12 转人工(固定话术)
任意状态 ──检测到注入──> S11 安全拒绝
任意状态 ──会话退款计数=4──> S7 拦截
任意状态 ──速率>20次/分钟──> S13 限流
```

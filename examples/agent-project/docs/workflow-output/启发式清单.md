## 二、典型高危区域汇总

- **安全注入**（H11-H14）：AI Agent 特有，传统功能测试测不出。
- **数据隔离**（H15-H17）：跨用户泄露是最高危漏洞。
- **HITL 权限**（H18-H20）：未授权高影响操作 100% 拦截是验收硬指标。
- **幻觉控制**（H24-H28）：幻觉率<5% 是验收指标。

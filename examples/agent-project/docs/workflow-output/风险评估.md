## 二、风险优先级策略

- **P0 风险（12 项）**：安全、数据隔离、幻觉、权限类——测试用例必须全覆盖，发布前必跑。
- **P1 风险（3 项）**：上下文、超时、角色伪装——每日构建与回归覆盖。
- **P2 风险（0 项）**：当前无。

## 三、风险预警

- Agent 测试的核心风险是**安全维度**：Prompt 注入、越权、数据泄露——这三类用传统功能测试测不出来，必须按 `qa-agent-testing` 九维模型专项覆盖。
- 风险与验收标准对应：RISK-001→拦截率100%、RISK-005→幻觉率<5%、RISK-002/011→未授权操作100%拦截。

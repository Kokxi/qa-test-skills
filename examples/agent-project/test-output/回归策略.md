| 变更类型 | 变更内容 | 影响模块 |

## 二、分级回归策略

### P0 冒烟回归（每次发布必跑，<15min）
- **覆盖范围**：核心主链路 + 最高风险安全项
- **用例**：TC-0001~0009、TC-0012~0014、TC-0018~0046、TC-0048、TC-0050~0056、TC-0059、TC-0062、TC-0064~0066、TC-0069~0070
- **内容**：身份声明、四大工具调用、注入拒绝、数据隔离、脱敏、HITL、退款次数、限流、幻觉控制、超时降级、审计

### P1 核心回归（合码阶段，<1h）
- **用例**：TC-0010/0011（上下文）、TC-0015/0016（咨询/投诉意图）、TC-0022/0023（工具选择确认）、TC-0047（超时临界）、TC-0049（稳定性抽样）、TC-0057/0058（异常格式/FAQ）、TC-0060/0061/0063（冲突数据/重试/混合意图）、TC-0067（会话边界占位）

### P2 全量回归（发布前/夜间）
- **用例**：TC-0068（101并发）、全量 80 条用例

## 五、自动化建议

- **自动化**：功能/权限/审计/限流用例（工具调用断言可自动化）。
- **自动断言+人工抽检**：幻觉（LLM 判定需人工复核）、注入（测试集自动跑，判定标准需确认）。
- **环境**：需要可控的模拟工具服务（可注入延迟/失败/恶意返回）——这是 Agent 回归的关键测试桩。

# 电商平台测试用例示例

## 项目简介

这是一个电商平台的测试用例示例，展示了如何使用根 SKILL.md 入口工作流从需求文档生成测试用例。

## 示例目的

1. **演示需求文档索引解析**：展示如何从主需求文档自动读取子模块需求
2. **展示测试用例生成流程**：展示完整的测试设计流程
3. **提供参考模板**：为其他项目提供测试用例模板

## 项目结构

```
ecommerce-project/
├── docs/
│   ├── prd.md                    # 主需求文档（包含索引引用）
│   └── requirements/
│       ├── 01-auth.md            # 用户认证模块需求
│       ├── 02-user.md            # 用户管理模块需求
│       ├── 03-product.md         # 商品管理模块需求
│       ├── 04-order.md           # 订单管理模块需求
│       ├── 05-payment.md         # 支付管理模块需求
│       └── 06-inventory.md       # 库存管理模块需求
├── test-cases.md                 # 生成的测试用例
└── README.md                     # 本说明文件
```

## 使用方法

可以参考这个示例项目的结构和测试用例格式，为自己的项目创建类似的测试用例。

3. 需求解构

5. 测试用例生成

## 示例内容

### 需求文档

- **主需求文档**：`docs/prd.md` - 包含项目概述和模块索引
- **子模块需求**：`docs/requirements/`目录下的6个需求文档

### 测试用例

- **测试用例统计**：120条测试用例（P0级85条，P1级35条）
- **生成方式**：qa-test-skills 根 SKILL.md 工作流（真实 LLM 完整执行，无人工约束）
- **覆盖模块**：认证（19）、用户（16）、商品（18）、订单（21）、支付（21）、库存（19）、非功能（6）
- **用例格式**：标准化格式，每条关联 REQ + SC，含优先级/类型/前置/步骤/期望

### 特点展示

1. **需求文档索引解析**：主文档引用子模块需求，技能自动读取
2. **测试用例结构化**：使用标准格式，便于管理和执行
3. **覆盖率分析**：提供需求覆盖率和测试用例分布分析
4. **风险提示**：识别需求缺失和测试覆盖风险
5. **边界与并发用例**：支付超时、库存超卖防护等边界/并发场景
6. **状态流转用例**：订单全生命周期状态转换验证

## 相关技能

- `qa-test-skills`：入口工作流，自动串联所有子技能
- `qa-requirement-review`：需求评审
- `qa-req-deconstruction`：需求解构
- `qa-scenario-tree`：场景树构建
- `qa-test-case-design`：测试用例设计

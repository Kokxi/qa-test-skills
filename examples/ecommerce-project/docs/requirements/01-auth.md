# 用户认证模块需求

## 1.1 登录功能
- **URL**: `/login`
- **表单字段**:
  - 用户名（文本输入，必填）
  - 密码（密码输入，带显示/隐藏切换）
  - 记住我（复选框）
- **按钮**: 登录
- **验证规则**:
  - 用户名不能为空
  - 密码不能为空
  - 连续错误登录5次后锁定账号30分钟

## 1.2 注册功能
- **URL**: `/register`
- **表单字段**:
  - 用户名（文本输入，必填，3-20个字符）
  - 邮箱（邮箱输入，必填，需验证格式）
  - 密码（密码输入，必填，至少8位，包含字母、数字、特殊字符）
  - 确认密码（密码输入，必填，需与密码一致）
- **按钮**: 注册
- **验证规则**:
  - 用户名不能重复
  - 邮箱不能重复
  - 密码强度要求：至少8位，包含大写字母、小写字母、数字、特殊字符中的3类

## 1.3 密码找回
- **URL**: `/forgot-password`
- **流程**:
  1. 输入注册邮箱
  2. 发送重置密码邮件
  3. 点击邮件中的链接
  4. 设置新密码
- **链接有效期**: 24小时

## 1.4 Session管理
- **默认超时时间**: 30分钟无操作自动退出登录
- **记住我**: 勾选后超时时间延长至7天
- **超时后行为**: 跳转到登录页面，用户需重新登录

# 支付管理模块需求

## 5.1 支付方式
- **URL**: `/payment/methods`
- **支持支付方式**:
  - 支付宝
  - 微信支付
  - 银行卡支付
  - 余额支付
- **默认支付方式**: 上次使用的支付方式
- **支付方式展示**: 订单确认页展示所有可用支付方式及图标

## 5.2 支付流程
- **URL**: `/payment/create`
- **流程**:
  1. 用户确认订单后发起支付
  2. 生成支付订单（关联订单号）
  3. 跳转到对应支付渠道（支付宝/微信/银行卡）
  4. 用户完成支付
  5. 支付回调通知
  6. 支付结果同步到订单
- **支付超时**: 30分钟未支付自动取消订单
- **支付金额**: 与订单实付金额一致，不允许修改

## 5.3 支付回调
- **URL**: `/payment/callback`（外部渠道回调）
- **回调处理**:
  - 校验回调签名（防伪造）
  - 校验支付金额与订单金额一致
  - 幂等处理（同一回调重复接收不重复处理）
  - 回调失败重试机制（最多3次，指数退避）
- **支付状态同步**:
  - 支付成功 → 订单状态更新为"已付款，待发货"
  - 支付失败 → 订单状态不变，用户可重新支付

## 5.4 退款
- **URL**: `/payment/refund`
- **退款规则**:
  - 支持部分退款（如部分商品退货）
  - 退款金额 ≤ 实付金额
  - 退款到原支付渠道
  - 退款处理时效：1-3个工作日
- **退款状态**:
  - 退款中
  - 退款成功
  - 退款失败（需人工介入）
- **退款与优惠**:
  - 使用优惠券的订单退款时，优惠按比例分摊
  - 全额退款时优惠券可退回

## 5.5 支付安全
- **安全要求**:
  - 支付金额展示防篡改（前端不信任，后端重新计算）
  - 支付签名校验（防中间人攻击）
  - 支付记录操作日志（可审计）
  - 敏感支付信息（银行卡号等）加密存储

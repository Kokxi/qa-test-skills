# 库存管理模块需求

## 6.1 库存查询
- **URL**: `/inventory/:skuId`
- **展示内容**:
  - 商品SKU库存数量
  - 已锁定库存（下单未支付）
  - 可售库存（总库存 - 锁定库存）
  - 库存状态（充足/预警/缺货）
- **库存预警阈值**: 可配置，默认低于10件触发预警

## 6.2 库存扣减
- **URL**: `/inventory/deduct`
- **触发时机**: 用户提交订单时
- **扣减规则**:
  - 下单即锁定库存（预占），不直接扣减
  - 支付成功后才真实扣减
  - 订单取消/超时未支付 → 释放锁定库存
- **扣减方式**: 原子操作，防止超卖
- **扣减失败**: 库存不足时下单失败，提示"库存不足"

## 6.3 库存锁定
- **URL**: `/inventory/lock`
- **锁定规则**:
  - 下单时锁定对应商品数量
  - 锁定有效期：与订单支付超时一致（30分钟）
  - 超时未支付 → 自动释放锁定
  - 锁定库存不参与可售计算
- **锁定冲突处理**:
  - 同一商品并发下单 → 按先到先得锁定
  - 库存只剩1件时并发下单 → 只有一个订单能锁定成功

## 6.4 库存补充
- **URL**: `/inventory/replenish`
- **触发时机**:
  - 后台手动补充
  - 采购入库自动更新
  - 退货入库自动回补
- **补充规则**:
  - 入库记录可追溯（采购单号/退货单号）
  - 补充后更新库存状态

## 6.5 库存盘点
- **URL**: `/inventory/stocktake`
- **盘点流程**:
  1. 创建盘点单
  2. 冻结盘点中的SKU（暂停销售）
  3. 人工清点录入实际数量
  4. 对比系统数量，生成差异
  5. 差异审核通过后调整系统库存
- **盘点差异处理**:
  - 差异记录留痕（谁盘、何时、差异多少）
  - 异常差异（>5%）需二次复核

## 6.6 库存异常
- **异常场景**:
  - 库存为负（超卖）：系统需自动拦截并告警
  - 库存数据不一致（数据库 vs Redis缓存）：定时对账修复
  - 并发扣减冲突：依赖数据库行锁/乐观锁保证原子性

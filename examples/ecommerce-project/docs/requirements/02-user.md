# 用户管理模块需求

## 2.1 用户信息管理
- **URL**: `/user/profile`
- **功能**:
  - 查看个人信息
  - 修改个人信息（姓名、手机号、头像）
  - 修改密码
  - 绑定/解绑邮箱

## 2.2 收货地址管理
- **URL**: `/user/addresses`
- **功能**:
  - 查看收货地址列表
  - 新增收货地址
  - 修改收货地址
  - 删除收货地址
  - 设置默认收货地址
- **字段**:
  - 收件人（必填）
  - 手机号（必填，需验证格式）
  - 省市区（必填，级联选择）
  - 详细地址（必填）
  - 邮政编码（选填）
  - 地址标签（选填：家、公司、其他）

## 2.3 用户权限
- **角色类型**:
  - 普通用户：浏览商品、下单购买
  - 商家：发布商品、管理订单
  - 管理员：系统管理、用户管理
- **权限控制**:
  - 不同角色访问不同功能
  - 未登录用户只能浏览商品，不能下单
  - 商家只能管理自己的商品和订单

# 订单管理模块需求

## 4.1 下单流程
- **URL**: `/order/create`
- **流程**:
  1. 选择商品和规格
  2. 选择收货地址
  3. 选择支付方式
  4. 确认订单信息
  5. 提交订单
- **订单信息**:
  - 商品信息（名称、规格、数量、单价）
  - 收货地址
  - 运费
  - 优惠信息
  - 实付金额
  - 支付方式

## 4.2 订单管理
- **URL**: `/user/orders`
- **订单状态**:
  - 待付款
  - 已付款，待发货
  - 已发货，待收货
  - 已完成
  - 已取消
  - 退款中
  - 已退款
- **功能**:
  - 查看订单列表（按状态筛选）
  - 查看订单详情
  - 取消订单（未发货时）
  - 确认收货
  - 申请退款
  - 删除订单（已完成/已取消）

## 4.3 订单详情
- **URL**: `/order/:id`
- **展示内容**:
  - 订单编号
  - 订单状态
  - 下单时间
  - 支付时间
  - 发货时间
  - 收货时间
  - 商品信息
  - 收货地址
  - 支付信息
  - 物流信息

## 4.4 退款流程
- **URL**: `/order/:id/refund`
- **流程**:
  1. 选择退款原因
  2. 填写退款说明
  3. 提交退款申请
  4. 等待审核
  5. 审核通过后退款
- **退款原因**:
  - 不想要了
  - 商品质量问题
  - 商品与描述不符
  - 收到商品损坏
  - 其他原因

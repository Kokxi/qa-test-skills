## 1. 业务上下文（Business Context）

```
项目：综合电商平台（用户/商品/订单/支付/库存）
复杂度：复杂档（资金/安全/并发/分布式）

非功能：页面<3s、1000+并发、99.9%可用、安全合规
需求规模：6模块、26个需求点、12项评审缺口(R1-R12)
```

## 2. 功能上下文（Functional Context）

### 核心功能清单（含状态机）
- 认证：登录/注册/找回/Session（锁定5次30min、链接24h、超时30min/7天）
- 用户：资料/地址(级联)/权限(三角色)
- 商品：列表(分页排序筛选)/详情(加购/购买/收藏)/搜索/三级分类
- 订单：下单/管理/详情/退款（7状态机，详见状态转换图）
- 支付：4渠道/流程(30min超时)/回调(签名+幂等+重试3次)/退款(部分/≤实付/原渠道/1-3工作日/优惠分摊)/安全(防篡改)
- 库存：查询(总量/锁定/可售/状态)/扣减(下单锁/支付扣/取消释放/原子防超卖)/锁定(30min/并发先到先得)/补充(留痕)/盘点(冻结/>5%复核)/异常(负库存/对账)

### 高优先级风险区域（回归/用例重点）
1. 支付回调并发一致性（重复/乱序/超时竞态）
2. 库存并发超卖（原子性、库存=1并发）
3. 退款金额精度与累计上限
4. 权限越权（水平/垂直）
5. 账号锁定/找回链接安全

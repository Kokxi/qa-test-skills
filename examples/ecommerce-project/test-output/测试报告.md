## 三、风险区域标注

### 极高风险（重点回归）
1. 支付回调并发一致性（TC_PAY_CB_007 / TC_BLIND_SEQ_001/002）
2. 库存并发超卖（TC_INV_LOCK_005/006）
3. 金额与退款精度（TC_ORDER_CRE_002 / TC_REFUND_003/004 / TC_BLIND_ACC_001）
4. 越权访问（TC_USER_PERM_002/003）

### 高风险
- 密码锁定/找回链接（TC_AUTH_LOGIN_005~007 / TC_AUTH_FPW_002~004）
- 支付金额篡改（TC_PAY_CRE_003）
- 回调签名（TC_PAY_CB_001/002）

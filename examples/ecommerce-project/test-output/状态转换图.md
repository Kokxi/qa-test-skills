## 1. 订单状态机

```
        ┌────────────┐ 提交订单    ┌────────────┐ 支付成功   ┌────────────┐ 发货      ┌────────────┐ 确认收货  ┌────────────┐
        │   初始      │───────────→│  待付款     │───────────→│  待发货     │──────────→│  已发货     │──────────→│  已完成     │
        └────────────┘            └─────┬──────┘            └────────────┘          └────────────┘          └────────────┘
               │                        │ 取消/支付超时30min                              │                     │
               │                        ↓                                         申请退款│                     │删除
               │                 ┌────────────┐                                    ↓                      ↓
               │                 │  已取消     │←──────────取消(未发货)──────────┐  退款中                  (逻辑删除)
               │                 └────────────┘                                 │     │成功
               │                                                                │     ↓
               │              (任意已支付状态)→退款中 → 已退款                    │  已退款
               │                                                                │失败→需人工介入
```

### 合法转换
| 转换 | 触发 | 前置 | 后置 |
|------|------|------|------|
| ST-01 | 提交订单 | 初始 | 待付款 |
| ST-02 | 支付成功回调 | 待付款 | 待发货 |
| ST-03 | 商家发货 | 待发货 | 已发货 |
| ST-04 | 确认收货 | 已发货 | 已完成 |
| ST-05 | 取消（未发货） | 待付款 | 已取消 |
| ST-06 | 支付超时30min | 待付款 | 已取消 |
| ST-07 | 申请退款 | 待发货/已发货/已完成 | 退款中 |
| ST-08 | 退款审核通过 | 退款中 | 已退款 |
| ST-09 | 删除 | 已完成/已取消 | 逻辑删除 |

### 非法转换（应被拦截）
| 转换 | 说明 | 预期 |
|------|------|------|
| ST-10 | 已发货→取消 | 拦截：仅未发货可取消 |
| ST-11 | 已完成→待付款 | 拦截 |
| ST-12 | 已取消→支付/发货 | 拦截 |
| ST-13 | 退款中→取消/确认收货 | 拦截：退款状态独占 |
| ST-14 | 已退款→再次退款 | 拦截 |
| ST-15 | 待发货→支付 | 拦截：已支付 |

### 并发/边界转换（高风险）
| 转换 | 场景 | 预期 |
|------|------|------|
| ST-16 | 支付成功回调 ∥ 超时取消 | 仅一个生效（回调成功则订单为待发货；否则已取消），最终一致 |
| ST-17 | 退款申请 ∥ 确认收货 | 状态机互斥，只允许一个进入 |
| ST-18 | 重复回调成功 | 幂等：不重复推进状态 |

## 2. 支付单状态机

```
待支付 ──发起──→ 支付中 ──回调成功──→ 已支付
   │               │                    │
   │ 30min超时      │回调失败            │ 发起退款
   ↓               ↓                    ↓
 已取消(订单侧)    待支付(可重付)        退款中 ──成功──→ 退款成功
                                          │失败
                                          ↓
                                      退款失败(人工介入)
```

## 3. 库存锁定状态机

```
可售 ──下单锁定──→ 已锁定 ──支付成功──→ 已扣减(真实库存)
  │                   │
  │                   └──取消/30min超时──→ 释放→可售
  └──补充入库──→ 可售增加
```

## 4. 盘点状态机

```
待盘点 ──冻结──→ 盘点中(冻结销售) ──清点录入──→ 差异待审 ──审核通过──→ 已调整(解冻)
                                                    └──差异>5%──→ 二次复核
```

## 5. 转换规则汇总

- 状态转换必须通过服务端校验（不信任前端）
- 所有含资金的状态转换需记录操作日志（审计）
- 非法/并发转换的最终一致性是测试重点（对应边界 BD-20/24）
- ⚠️ R9 缺口：退款失败时订单侧状态未定义（预留标注）

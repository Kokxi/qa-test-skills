# 需求文档集合（合并版）

> 第0步产出 · 来源：`docs/prd.md` + `docs/requirements/01~06`

## 一、项目概述

综合电商平台，含用户、商品、订单、支付、库存核心模块。
技术栈：React + TypeScript / Node.js + Express / MySQL + Redis / Docker + K8s。
非功能需求：页面加载 <3s；支持 1000+ 并发用户；数据加密、权限控制、防SQL注入；99.9%可用性。

## 二、模块需求明细

### 模块1：用户认证（01-auth.md）
| 编号 | 需求点 | 规则 |
|------|--------|------|
| A1 | 登录 /login | 用户名+密码+记住我；用户名/密码非空；连续错误5次锁定账号30分钟 |
| A2 | 注册 /register | 用户名3-20字符唯一；邮箱必填格式校验唯一；密码≥8位含字母/数字/特殊字符；确认密码一致 |
| A3 | 密码找回 /forgot-password | 输入注册邮箱→发重置邮件→点击链接→设置新密码；链接有效期24小时 |
| A4 | Session管理 | 默认30分钟无操作超时；记住我=7天；超时跳登录页 |

### 模块2：用户管理（02-user.md）
| 编号 | 需求点 | 规则 |
|------|--------|------|
| U1 | 个人资料 /user/profile | 查看/修改姓名/手机号/头像；修改密码；绑定/解绑邮箱 |
| U2 | 收货地址 /user/addresses | 列表/新增/修改/删除/设默认；字段：收件人(必填)、手机号(格式)、省市区(级联必填)、详细地址(必填)、邮编(选填)、标签(家/公司/其他选填) |
| U3 | 用户权限 | 普通用户/商家/管理员三角色；未登录仅浏览不能下单；商家只能管自己的商品订单 |

### 模块3：商品管理（03-product.md）
| 编号 | 需求点 | 规则 |
|------|--------|------|
| P1 | 商品浏览 /products | 列表分页/排序/筛选（价格范围/分类/品牌/销量/评分） |
| P2 | 商品详情 /product/:id | 多图轮播、名称/价格/描述/规格/库存/销量/评分/评价列表；操作：加购/立即购买/收藏 |
| P3 | 商品搜索 /search | 关键词/搜索历史/热门搜索/排序（综合/销量/价格/评分） |
| P4 | 商品分类 | 三级分类（一级/二级/三级）；首页分类导航+分类页筛选 |

### 模块4：订单管理（04-order.md）
| 编号 | 需求点 | 规则 |
|------|--------|------|
| O1 | 下单 /order/create | 选商品规格→选地址→选支付方式→确认→提交；订单含商品/地址/运费/优惠/实付/支付方式 |
| O2 | 订单管理 /user/orders | 状态：待付款/待发货/已发货/已完成/已取消/退款中/已退款；列表筛选；详情；取消(未发货时)；确认收货；申请退款；删除(已完成/已取消) |
| O3 | 订单详情 /order/:id | 订单号/状态/下单/支付/发货/收货时间/商品/地址/支付/物流 |
| O4 | 退款流程 /order/:id/refund | 选原因→填说明→提交→审核→退款；原因：不想要了/质量问题/描述不符/收到损坏/其他 |

### 模块5：支付管理（05-payment.md）
| 编号 | 需求点 | 规则 |
|------|--------|------|
| M1 | 支付方式 /payment/methods | 支付宝/微信/银行卡/余额；默认=上次使用；确认页展示 |
| M2 | 支付流程 /payment/create | 确认→生成支付单(关联订单号)→跳渠道→支付→回调→同步订单；超时30分钟自动取消；金额=实付不可改 |
| M3 | 支付回调 /payment/callback | 签名校验/金额一致性/幂等/重试最多3次指数退避；成功→"已付款待发货"；失败→订单不变可重付 |
| M4 | 退款 /payment/refund | 支持部分退款；退款≤实付；退原渠道；1-3工作日；退款中/成功/失败(人工)；优惠按比例分摊；全额退款优惠券退回 |
| M5 | 支付安全 | 金额防篡改(后端重算)；签名校验；操作日志可审计；卡号加密存储 |

### 模块6：库存管理（06-inventory.md）
| 编号 | 需求点 | 规则 |
|------|--------|------|
| I1 | 库存查询 /inventory/:skuId | 总量/锁定/可售(总-锁)/状态(充足/预警/缺货)；预警阈值可配默认<10 |
| I2 | 库存扣减 /inventory/deduct | 下单锁定(预占)；支付成功才真实扣减；取消/超时释放；原子防超卖；不足提示"库存不足" |
| I3 | 库存锁定 /inventory/lock | 下单锁定；有效期=支付超时30分钟；超时自动释放；锁定不参与可售；并发先到先得；仅剩1件并发只有一个成功 |
| I4 | 库存补充 /inventory/replenish | 手动/采购入库/退货回补；入库记录可追溯(采购/退货单号)；补充后更新状态 |
| I5 | 库存盘点 /inventory/stocktake | 建盘点单→冻结SKU→清点录入→对比差异→审核调整；差异留痕；异常差异(>5%)二次复核 |
| I6 | 库存异常 | 负库存拦截告警；DB vs Redis 不一致定时对账；并发扣减靠行锁/乐观锁 |

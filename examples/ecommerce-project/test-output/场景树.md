## 模块A 认证（01-auth）

### 主路径
- SC-A01-M 正确用户名+正确密码登录成功
- SC-A02-M 勾选"记住我"登录，7天后仍有效
- SC-A03-M 注册：合法信息注册成功并自动登录
- SC-A04-M 密码找回：邮箱→收邮件→点链接→设新密码→新密码登录成功

### 备选路径
- SC-A05-A 忘记密码走"找回密码"入口（而非登录失败）
- SC-A06-A 已有账号重复注册提示"用户名已存在"
- SC-A07-A 密码错误提示"用户名或密码错误"，不区分具体哪个错

### 异常路径
- SC-A08-E 用户名/密码为空提交拦截
- SC-A09-E 用户名不存在提示（与密码错误同文案，防账号枚举）
- SC-A10-E 第5次错误登录：锁定且提示剩余解锁时间
- SC-A11-E 锁定期间（30分钟内）继续尝试登录被拒
- SC-A12-E 锁定30分钟结束后可正常登录，计数器清零
- SC-A13-E 找回密码链接24小时后点击失效
- SC-A14-E 已使用的找回链接再次点击失效（防重放）
- SC-A15-E 点击邮件链接时的浏览器被篡改用户标识（越权重置他人密码）
- SC-A16-E 注册用户名2/20/21字符边界；密码不满足强度；确认密码不一致
- SC-A17-E 重复邮箱注册提示"邮箱已被注册"

### 业务规则
- SC-A18-R 密码强度：8位含大写+小写+数字+特殊字符中3类（按 R1 澄清后规则）
- SC-A19-R 连续错误计数在"成功登录/解锁/注册"后重置
- SC-A20-R 会话超时30分钟无操作自动退出跳登录页，记住我7天

## 模块B 用户（02-user）

### 主路径
- SC-B01-M 查看个人信息展示完整
- SC-B02-M 修改姓名/手机号/头像保存成功
- SC-B03-M 修改密码成功，旧密码失效需重新登录
- SC-B04-M 绑定邮箱成功；解绑邮箱成功
- SC-B05-M 新增收货地址并设为默认
- SC-B06-M 修改收货地址成功
- SC-B07-M 删除非默认地址成功

### 备选路径
- SC-B08-A 已有默认地址时新增地址不做默认
- SC-B09-A 设置新默认地址时旧默认自动取消（唯一默认）
- SC-B10-A 删除默认地址后系统自动指定一个剩余地址为默认

### 异常路径
- SC-B11-E 手机号格式非法（位数/字符）拦截
- SC-B12-E 省市区未级联选择到底、详细地址为空拦截
- SC-B13-E 修改密码时旧密码错误/新密码与原密码相同
- SC-B14-E 绑定邮箱为已占用邮箱提示冲突
- SC-B15-E 未登录访问 /user/profile → 跳登录并保留回跳地址
- SC-B16-E 普通用户访问商家管理接口 → 403 无权限
- SC-B17-E 商家访问/修改他人商品或订单 → 越权拦截
- SC-B18-E 并发两个会话同时修改同一资料，后写覆盖（版本控制）

### 业务规则
- SC-B19-R 角色权限：未登录仅浏览禁下单；商家仅自有商品订单；管理员全量
- SC-B20-R 地址字段：收件人/手机号/省市区/详细地址必填；邮编标签选填

- SC-C20-R 筛选价格区间需廉价逻辑（最低≤最高）

## 模块D 订单（04-order）

### 主路径
- SC-D01-M 完整下单：选规格→地址→支付方式→确认→提交→生成待付款订单
- SC-D02-M 订单详情展示全部字段与时间线
- SC-D03-M 未发货订单取消成功，库存释放
- SC-D04-M 已发货订单确认收货→已完成
- SC-D05-M 申请退款→退款中→退款成功→已退款

### 备选路径
- SC-D06-A 订单列表按状态筛选（待付款/待发货/…）
- SC-D07-A 已完成/已取消订单删除（逻辑删除，有支付记录不可物理删）
- SC-D08-A 免运费 / 需运费两种情况下单金额正确

### 异常路径
- SC-D09-E 多个规格/商品下单金额计算错误校验（单价×数量+运费-优惠=实付）
- SC-D10-E 无收货地址下单 → 拦截并引导新增
- SC-D11-E 库存不足下单失败并提示"库存不足"
- SC-D12-E 重复点击提交订单 → 仅生成一个订单（幂等）
- SC-D13-E 待付款+支付超时 → 自动取消订单，库存释放
- SC-D14-E 已发货订单尝试取消 → 拦截
- SC-D15-E 退款中订单尝试取消/确认收货 → 状态机拦截
- SC-D16-E 已取消/已删除订单再次支付/退款 → 拒绝
- SC-D17-E 订单删除后详情仍可通过订单号查询（审计）

### 业务规则
- SC-D18-R 订单状态机合法流转：待付款→待发货→已发货→已完成；待付款→已取消；任意→退款中→已退款
- SC-D19-R 取消前提=未发货；删除前提=已完成或已取消
- SC-D20-R 退款原因5种必选，说明文本长度边界

## 模块E 支付（05-payment）

### 主路径
- SC-E01-M 支付宝支付全流程成功，订单变"已付款待发货"
- SC-E02-M 微信/银行卡/余额支付成功
- SC-E03-M 支付回调签名正确处理成功
- SC-E04-M 支付失败后重新支付成功

### 备选路径
- SC-E05-A 默认支付方式=上次使用，确认页展示4种方式
- SC-E06-A 余额不足时余额支付失败→切换其它渠道

### 异常路径
- SC-E07-E 支付金额被篡改（前端改价/抓包改金额）→ 后端重算拒绝
- SC-E08-E 伪造回调签名 → 拒绝且记录
- SC-E09-E 回调金额与订单金额不一致 → 拒绝
- SC-E10-E 重复回调（相同参数两次）→ 幂等处理只记一次
- SC-E11-E 回调失败重试3次、指数退避，超过后标记异常需人工
- SC-E12-E 支付超时30分钟自动取消（与订单同步）
- SC-E13-E 支付成功回调 vs 取消订单并发 → 最终一致且不双状态
- SC-E14-E 乱序回调（先到"支付成功"后无异常；重复成功不降级）
- SC-E15-E 卡号等敏感信息非加密展示 → 加密校验日志

### 业务规则
- SC-E16-R 支付金额=订单实付，不允许修改
- SC-E17-R 回调 ack 语义：重复接收不重复处理（幂等键=订单号+渠道）

### 主路径
- SC-F01-M 全额退款至原渠道成功
- SC-F02-M 部分退款（数组件退货）成功

### 备选路径
- SC-F03-A 退款失败 → 状态"退款失败"标记需人工介入

### 异常路径

- SC-F05-E 累计退款 > 实付金额（先部分退再全退）→ 超限拦截

- SC-F07-E 全额退款优惠券退回账户
- SC-F08-E 已付款但未发货订单退款 → 校验订单状态合法性

### 业务规则
- SC-F10-R 退款状态机：退款中→成功/失败；失败人工介入后可重试

## 模块G 库存（06-inventory）

### 主路径
- SC-G01-M 库存查询展示总量/锁定/可售/状态
- SC-G02-M 下单成功锁定库存（不扣减）
- SC-G03-M 支付成功后真实扣减
- SC-G04-M 取消/超时未支付释放锁定
- SC-G05-M 手动/采购/退货补充入库并留痕

### 备选路径
- SC-G06-A 预警阈值可配置（默认<10），配置后状态刷新
- SC-G07-A 盘点流程：建单→冻结→清点→差异→审核调整

### 异常路径
- SC-G08-E 库存≥10 → 充足；1-9 → 预警；0 → 缺货边界
- SC-G09-E 可售=总-锁定计算准确性（多发锁定叠加）
- SC-G10-E 库存不足下单 → 锁定失败提示"库存不足"
- SC-G11-E 库存=1时两个并发下单 → 仅一个锁定成功
- SC-G12-E 高并发扣减无超卖（原子操作）
- SC-G13-E 负库存自动拦截+告警
- SC-G14-E DB与Redis库存不一致 → 定时对账修复
- SC-G15-E 锁定超时（30分钟）自动释放，恢复可售
- SC-G16-E 冻结盘点中SKU → 暂停销售/下单拦截
- SC-G17-E 盘点差异>5% → 触发二次复核
- SC-G18-E 并发扣减冲突 → 行锁/乐观锁回滚不超卖

### 业务规则
- SC-G19-R 扣减时机：锁定=下单，实际扣减=支付成功
- SC-G20-R 锁定不参与可售；释放恢复可售；补充更新状态

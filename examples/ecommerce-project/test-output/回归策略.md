# 回归策略

> 第5步产出 · 技能：qa-regression-testing
> 适用场景：电商平台迭代/冒烟/发版

---

## 1. 回归级别与范围

| 级别 | 范围 | 执行时机 | 预估时长 |
|------|------|---------|---------|
| 冒烟回归(P0) | 登录→搜索→下单→支付→确认收货 主链路 10 条 | 每轮提测 | ~30分钟 |
| 核心回归(P1) | 订单状态机+支付回调+库存并发+退款 30 条 | 合码前 | ~2小时 |
| 全量回归 | 全部用例集 | 发版前 | ~1天 |

## 2. 筛选策略（风险驱动）

| 优先级 | 筛选依据 | 覆盖用例 |
|--------|---------|---------|
| 最高 | 资金链路（支付回调/退款/金额精度） | 场景树 E/F 组 + 边界 BD-20/24/27 |
| 最高 | 库存并发（超卖/锁定/释放） | 场景树 G 组 + BD-25 |
| 高 | 认证安全（锁定/找回/越权） | 场景树 A/B 组 + BD-13/17 |
| 中 | 列表/搜索/筛选 | 场景树 C 组 |
| 变更驱动 | 具体代码变更影响面（qa-code-review-for-test） | 按影响范围勾选 |

## 3. 回归用例清单（按变更模块勾选）

| 变更模块 | 必回归用例 | 对应场景 |
|---------|-----------|---------|
| 支付 | 支付回调幂等/重试/金额校验、超时取消 | SC-E01~E17, SC-F01~F10 |
| 订单 | 状态机全转换 + 非法转换拦截 + 并发 | SC-D01~D20, SC-ST01~ST18 |
| 库存 | 锁定/释放/扣减/对账/并发 | SC-G01~G20 |
| 认证 | 锁定/找回链接/越权 | SC-A01~A20 |
| 用户 | 地址/资料/权限 | SC-B01~B20 |
| 商品 | 列表/搜索/筛选/详情 | SC-C01~C20 |

## 4. 未覆盖风险区域报告

- ⚠️ 购物车、优惠券、评价、物流模块**未覆盖**（需求缺口 R2-R5，不编造用例）
- ⚠️ 退款失败订单状态未定义（R9）→ 回归时按"人工介入"假设执行，规则澄清后补充
- ⚠️ 第三方支付沙箱依赖 → 需要 Mock 网关才能回归回调链路

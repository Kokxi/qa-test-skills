# 启发式清单

> 第3步产出 · 技能：qa-heuristic-checklist
> 按功能类型核对：登录/支付/下单/权限/搜索/地址

## 1. 登录功能清单
- [x] 必填校验（空用户名/空密码）
- [x] 错误密码提示（正确/错误/空）
- [x] 连续错误 5 次锁定（第5次边界、锁定30分钟精确计时）
- [x] 解锁后计数器清零
- [x] 记住我 → 7天、不勾选 → 30分钟
- [x] 密码显示/隐藏切换
- [x] 锁定期间其它端登录被拒
- [x] 登录成功后跳转原页面

## 2. 支付功能清单
- [x] 金额与订单实付强一致（前端篡改后端重算）
- [x] 支付超时 30 分钟自动取消
- [x] 回调签名校验（伪造签名拒绝）
- [x] 回调幂等（重复回调不重复处理）
- [x] 回调失败重试 3 次指数退避
- [x] 支付成功→订单"已付款待发货"；失败→订单不变可重付
- [x] 退款 ≤ 实付、部分退款、原渠道退回
- [x] 优惠券退款按比例分摊，全额退券
- [x] 敏感卡号加密存储
- [x] 支付日志可审计

## 3. 下单/购物车链路清单
- [x] 商品规格选择必选
- [x] 收货地址必选（无默认地址时引导新增）
- [x] 库存不足拦截（下单失败提示）
- [x] 下单幂等（重复点击不重复下单）
- [x] 运费/优惠/实付金额计算正确
- [x] 下单成功→锁定库存→订单待付款
- [x] 取消订单→释放库存

## 4. 权限清单
- [x] 未登录浏览商品、禁止下单跳登录
- [x] 普通用户/商家/管理员功能隔离
- [x] 商家只能管自己的商品/订单（水平越权）
- [x] 管理员/商家不可访问对方的专用接口（垂直越权）

## 5. 搜索/列表清单
- [x] 关键词空值/超长/特殊字符
- [x] 分页边界（首页/尾页/超范围页码）
- [x] 组合筛选（价格+分类+品牌）
- [x] 排序正确性（综合/销量/价格/评分）
- [x] 搜索历史记录/热门词展示
- [x] 无结果提示

## 6. 收货地址清单
- [x] 必填字段校验（收件人/手机号/省市区/详细地址）
- [x] 手机号格式校验
- [x] 邮编选填格式校验
- [x] 级联省市区联动
- [x] 默认地址唯一（新设默认时旧默认自动取消）
- [x] 删除默认地址处理

## 7. 库存深度清单
- [x] 库存状态阈值（≥10 充足 / <10 预警 / =0 缺货）
- [x] 可售=总-锁定 计算
- [x] 下单锁定、支付扣减、取消/超时释放
- [x] 库存=1 并发下单只有一个成功
- [x] 负库存拦截告警
- [x] 盘点差异 >5% 二次复核

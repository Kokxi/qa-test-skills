## 2. 隐性需求（文档没写但必须满足）

| 编号 | 隐性需求 | 依据 |
|------|---------|------|
| H1 | 登录/注册/找回密码表单的 XSS 与 SQL 注入防护 | PRD 安全要求 |
| H2 | 密码存储必须加盐哈希（不存明文/不可逆） | 行业基线 + 安全要求 |
| H3 | 重复提交防护（注册、下单、支付幂等） | 防重复扣款/重复下单 |
| H4 | 未登录访问受保护资源 → 跳转登录且保留回跳地址 | U3 权限语义 |
| H5 | 并发修改同一地址/资料 → 后写覆盖前写的版本控制 | 数据一致性 |
| H6 | 支付回调与订单状态更新的并发一致性（重复回调、乱序回调） | M3 |
| H7 | 库存 Redis 缓存与 MySQL 一致性、缓存雪崩/穿透 | I6 + 架构 |
| H8 | 订单删除只能逻辑删除（有支付/退款记录不可物理删） | 审计要求 |
| H9 | 退款金额与优惠分摊计算的精度（分/厘） | 资金链路 |
| H10 | 移动端/不同浏览器的支付回调到达差异、页面刷新时机 | 支付场景 |

## 4. 五维拆解（输入/操作/状态/输出/规则）

### 4.1 认证模块（A1-A4）
| 维度 | 内容 |
|------|------|
| 输入 | 用户名、密码、记住我、邮箱、新密码、确认密码、重置令牌 |
| 操作 | 登录、注册、提交找回、点击重置链接、设置新密码、退出 |
| 状态 | 未登录 / 已登录 / 锁定中(30min) / 重置链接有效 / 重置链接过期 |
| 输出 | 登录成功JWT/Session、表单错误提示、锁定提示、重置邮件、重置成功页 |
| 规则 | 错误5次锁30min；用户名3-20；密码强度；链接24h；超时30min/7天 |

### 4.2 用户模块（U1-U3）
| 维度 | 内容 |
|------|------|
| 输入 | 姓名、手机号、头像、旧/新密码、邮箱、地址字段 |
| 操作 | 查看/修改资料、改密、绑定/解绑邮箱、地址CRUD、设默认 |
| 状态 | 资料完整/不完整、默认地址存在/不存在、邮箱已绑/未绑 |
| 输出 | 资料保存成功、地址列表、默认标记、权限拒绝提示 |
| 规则 | 手机号格式；省市区级联；唯一默认地址；三角色权限 |

### 4.3 商品模块（P1-P4）
| 维度 | 内容 |
|------|------|
| 输入 | 页码、排序字段、筛选条件、关键词、分类ID |
| 操作 | 浏览、筛选、排序、搜索、查看详情、加购、收藏 |
| 状态 | 列表页/详情页/搜索页/分类页 |
| 输出 | 商品列表、分页信息、详情数据、搜索结果、收藏成功 |
| 规则 | 分页边界；筛选组合；三级分类；上下架状态影响展示 |

### 4.4 订单模块（O1-O4）
| 维度 | 内容 |
|------|------|
| 输入 | 商品规格数量、地址ID、支付方式、退款原因说明 |
| 操作 | 下单、取消、确认收货、申请退款、删除、查看 |
| 状态 | 待付款→待发货→已发货→已完成；待付款→已取消；→退款中→已退款 |
| 输出 | 订单号、订单详情、状态流转、退款单号 |
| 规则 | 未发货可取消；已完成/已取消可删；退款原因5种 |

### 4.5 支付模块（M1-M5）
| 维度 | 内容 |
|------|------|
| 输入 | 订单号、支付方式、回调报文、退款金额 |
| 操作 | 发起支付、渠道跳转、回调处理、退款 |
| 状态 | 待支付/支付中/已支付/支付失败/退款中/退款成功/退款失败 |
| 输出 | 支付单、支付链接、回调ack、退款结果 |
| 规则 | 30min超时；金额不可改；签名校验；幂等；重试3次；退款≤实付；1-3工作日 |

### 4.6 库存模块（I1-I6）
| 维度 | 内容 |
|------|------|
| 输入 | SKU ID、下单数量、采购/退货单号、盘点数量 |
| 操作 | 查询、锁定、扣减、释放、补充、盘点、对账 |
| 状态 | 充足/预警/缺货；锁定中/可售；盘点冻结中 |
| 输出 | 库存数量、锁定结果、扣减结果、盘点差异单 |
| 规则 | 原子扣减防超卖；锁定30min；释放条件；预警<10；盘点差异>5%复核 |

# QA Test Skills - 软件测试技能集

> 45个专家级测试技能，覆盖测试全生命周期

## 项目背景

### 解决什么问题？

初级测试人员使用AI时，只会问"帮我生成XX模块的测试用例"，AI不知道上下文和背景，回答也很宽泛，导致AI辅助测试效果不佳。

### 我们的方案

**用户提问方式不变**，技能集在后台帮他完成专家级测试设计：
- 构建业务上下文
- 挖掘隐性需求
- 识别风险区域
- 生成结构化用例
- 评审和补盲

### 核心价值

- **零学习成本**：用户无需改变现有习惯
- **专家级输出**：资深测试经验编码为可加载技能
- **完整追溯链**：需求→场景→用例→评审，全程可追溯
- **持续优化**：专家评审+元学习，越用越好

## 如何使用

### 安装

```bash
# 克隆仓库
git clone https://github.com/Kokxi/qa-test-skills.git

# 安装插件
/plugin dir ./qa-test-skills
```

### 快速开始

```bash
# 直接输入需求，自动执行完整工作流
帮我生成购物车模块的测试用例

# 上传需求文档
[上传PRD文档] 帮我生成测试用例

# 给URL链接
https://xxx.com/api-docs 帮我生成接口测试用例
```

### 单独使用技能

```bash
# 需求解构
帮我解构这个需求：[需求描述]

# 边界分析
帮我分析这个场景的边界：[场景描述]

# Bug报告
帮我写Bug报告：[Bug描述]
```

## 工作流

```
用户输入 → 智能识别 → 需求评审 → 需求解构 → 场景构建 → 深度设计 → 上下文工程 → 提示词生成 → AI生成 → 输出评审 → 盲区补盲 → 测试报告
```

详见 [测试标准与规范](docs/standards.md)
